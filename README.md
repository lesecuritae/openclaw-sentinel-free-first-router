An installable OpenClaw plugin that selects the least costly capable configured model profile before an agent turn. It contains no provider credentials or deployment-specific settings.

Ein installierbares OpenClaw-Plugin, das vor einem Agentendurchlauf das günstigste geeignete konfigurierte Modellprofil auswählt. Es enthält keine Anbieter-Zugangsdaten oder einsatzspezifischen Einstellungen.
